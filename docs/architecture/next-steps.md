# Công việc còn lại theo kế hoạch 16 tuần

1. Hoàn tất PRD/use cases và review phạm vi với chủ dự án. Tạo GitHub repo, board và branch protection khi có repository đích.
2. Thêm migration tường minh cho users/workspaces/members, JWT/OIDC, RBAC và kiểm thử cross-workspace.
3. Bổ sung task state machine, DAG, lease/timeout, retry scheduler, cancellation và approval.
4. Tích hợp LangGraph checkpoint; PM/Architect/Developer/QA agents với model router và structured outputs.
5. Chạy code sinh bởi agent trong sandbox cô lập, giới hạn resource/network; Git worktree riêng và PR qua CI/review.
6. Thêm React dashboard, realtime event gateway, message timeline và cost report.
7. Kiểm thử Kafka crash/rebalance, staging, backup/restore, bảo mật, benchmark và hai demo nghiệm thu.

Không đánh dấu các gate tuần là hoàn thành trước khi kiểm thử theo điều kiện trong tài liệu gốc.
